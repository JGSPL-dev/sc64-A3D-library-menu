# Source code

This menu is a modified version of N64FlashcartMenu (AGPL-3.0). The complete source is here in two forms:

- `sc64-library-source.patch`: one git patch against the N64FlashcartMenu `V0.3.5` tag.
  Apply it with `git apply --binary sc64-library-source.patch`.
- `sc64-library.bundle`: the full commit history of the changes, as a git bundle.
  Fetch it into a clone that has the V0.3.5 tag with `git fetch sc64-library.bundle HEAD:library`.

See "Building from source" in README.md.

If you got this menu from someone else, you are entitled to this source under the AGPL-3.0.
If you share the menu, share this folder (or a link to the source) with it.
